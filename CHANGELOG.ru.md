1.8.0

1.7.0
• Обновление в один клик: KeyFish скачивает новую версию с GitHub, проверяет контрольную сумму и перезапускается
• Учится у вас: слово, которое вы исправили через Pause, в следующий раз исправится само
• Тихий режим: в играх и полноэкранных программах ничего не исправляется
• Поля паролей не трогаются ни в одной программе, включая браузеры — там ничего не исправляется и не запоминается
• Статистика: сколько ошибок поймала рыбка
• Релизы теперь собирает GitHub Actions

• Проверка обновлений на GitHub
