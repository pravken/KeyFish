2.0.0
• 19 языков: английский, немецкий, польский, французский, испанский, итальянский, португальский, чешский, турецкий, сербская латиница ⇄ русский, украинский, белорусский, болгарский, македонский, сербская кириллица, греческий, иврит, грузинский. KeyFish берёт раскладки, установленные в Windows, и исправляет слова, набранные в раскладке другого алфавита
• Работает с любым расположением клавиш (QWERTZ, AZERTY, буквы через AltGr или через клавиши ударений, как греческий ΄ или французский ^): клавиши отслеживаются по их месту на клавиатуре
• Если установлено несколько раскладок, KeyFish определяет язык по слову и по предыдущим словам — украинское слово уйдёт в украинскую раскладку
• Сербский пишут обоими алфавитами, поэтому правильное слово на сербской латинице никогда не «исправляется» в кириллицу; сербская кириллица, македонская и греческая раскладки фонетические, поэтому набранное в них исправляется, только если слово есть в словаре
• Раскладка для программы: выберите раскладку для Telegram, VS Code и т. д. — KeyFish включит её, когда вы перейдёте в эту программу
• Новые настройки в стиле Windows 11, с тёмной темой как в Windows; автозамены, программы и слова — теперь таблицы с кнопками «Добавить» и «Удалить» вместо текста
• Интерфейс теперь и на украинском, белорусском, немецком, польском, сербском, французском и испанском
• Чёткая картинка на экранах с масштабированием; меню рыбки в трее в теме Windows
• Рыбка нарисована заново, подробнее, а в окне «О программе» спрятан сюрприз 🐟
• Pause на выделенном тексте переводит его в вашу другую установленную раскладку, а не только английская ⇄ русская
• Новая кнопка «Поддержать ☕» в окне «О программе» и в настройках
• Надёжнее: если Windows тихо отключит слежение KeyFish за клавиатурой (так она поступает с программой, которая однажды ответила слишком медленно), KeyFish заметит это и включит его снова; файлы читаются и пишутся в фоне, чтобы набор никогда не подтормаживал
• Терминалы, SSH-клиенты, виртуальные машины, удалённые рабочие столы и ещё несколько менеджеров паролей исключены по умолчанию (в ваш список добавляются один раз)
• Текст, который KeyFish кладёт в буфер обмена, не попадает в журнал буфера (Win+V) и облачную синхронизацию
• Исправлено: обратная косая черта в автозамене (C:\new) после сохранения превращалась в перенос строки; сокращения с цифрами (адр1) не срабатывали; слова, которые KeyFish выучил, пока были открыты настройки, терялись при сохранении; буквы, набранные очень быстро сразу после исправления, могли потерять Shift; в VS Code и Visual Studio Pause без выделения добавлял исправленную копию всей строки
• KeyFish запускается даже из папки только для чтения, например Program Files: его файлы тогда хранятся в %APPDATA%\KeyFish
• У каждого релиза есть подписанное подтверждение сборки (см. README)
